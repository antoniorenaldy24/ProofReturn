# ADR-002: React + TypeScript + Vite monorepo with four apps

- Status: Accepted
- Date: 2026-10-27
- Related IDs: Section 39

## Context

Documented in ProofReturn SSOT v1.2.1 (Section 46.2) to govern system architecture, mechanism integrity, and compliance for `Section 39`.

## Decision

React + TypeScript + Vite monorepo with four apps

## Alternatives considered

Evaluated against alternative architectural and mechanism options during SSOT v1.0, v1.1, v1.2, and v1.2.1 audits (see Appendices E and F).

## Consequences (positive, negative, follow-ups)

- **Key reason / positive impact**: Shared UI and generated client
- **Traceability**: Enforced via `Section 39` and verified at release gates (Section 27).
