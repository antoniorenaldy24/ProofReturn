# ADR-014: Fast Lane scoped per merchant by default

- Status: Accepted
- Date: 2026-10-27
- Related IDs: D-04

## Context

Documented in ProofReturn SSOT v1.2.1 (Section 46.2) to govern system architecture, mechanism integrity, and compliance for `D-04`.

## Decision

Fast Lane scoped per merchant by default

## Alternatives considered

Evaluated against alternative architectural and mechanism options during SSOT v1.0, v1.1, v1.2, and v1.2.1 audits (see Appendices E and F).

## Consequences (positive, negative, follow-ups)

- **Key reason / positive impact**: Privacy; opt-in cross-merchant
- **Traceability**: Enforced via `D-04` and verified at release gates (Section 27).
