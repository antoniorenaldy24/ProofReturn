# ADR-004: Integer minor units + Decimal/Fraction arithmetic

- Status: Accepted
- Date: 2026-10-27
- Related IDs: DB-01, 25.3

## Context

Documented in ProofReturn SSOT v1.2.1 (Section 46.2) to govern system architecture, mechanism integrity, and compliance for `DB-01, 25.3`.

## Decision

Integer minor units + Decimal/Fraction arithmetic

## Alternatives considered

Evaluated against alternative architectural and mechanism options during SSOT v1.0, v1.1, v1.2, and v1.2.1 audits (see Appendices E and F).

## Consequences (positive, negative, follow-ups)

- **Key reason / positive impact**: Exact money math
- **Traceability**: Enforced via `DB-01, 25.3` and verified at release gates (Section 27).
