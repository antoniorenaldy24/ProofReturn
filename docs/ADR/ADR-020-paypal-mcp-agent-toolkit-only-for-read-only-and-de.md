# ADR-020: PayPal MCP / Agent Toolkit only for read-only and developer use

- Status: Accepted
- Date: 2026-10-27
- Related IDs: Section 10.7

## Context

Documented in ProofReturn SSOT v1.2.1 (Section 46.2) to govern system architecture, mechanism integrity, and compliance for `Section 10.7`.

## Decision

PayPal MCP / Agent Toolkit only for read-only and developer use

## Alternatives considered

Evaluated against alternative architectural and mechanism options during SSOT v1.0, v1.1, v1.2, and v1.2.1 audits (see Appendices E and F).

## Consequences (positive, negative, follow-ups)

- **Key reason / positive impact**: Keeps `INV-05`
- **Traceability**: Enforced via `Section 10.7` and verified at release gates (Section 27).
