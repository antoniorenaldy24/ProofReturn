# ADR-010: MCP server transport; schemas as UCP/ACP-aligned extension

- Status: Accepted
- Date: 2026-10-27
- Related IDs: F-10

## Context

Documented in ProofReturn SSOT v1.2.1 (Section 46.2) to govern system architecture, mechanism integrity, and compliance for `F-10`.

## Decision

MCP server transport; schemas as UCP/ACP-aligned extension

## Alternatives considered

Evaluated against alternative architectural and mechanism options during SSOT v1.0, v1.1, v1.2, and v1.2.1 audits (see Appendices E and F).

## Consequences (positive, negative, follow-ups)

- **Key reason / positive impact**: Agent readiness without competing with protocols
- **Traceability**: Enforced via `F-10` and verified at release gates (Section 27).
