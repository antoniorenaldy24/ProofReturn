# ADR-013: MIT license; permissive-only dependencies

- Status: Accepted
- Date: 2026-10-27
- Related IDs: DEP-05

## Context

Documented in ProofReturn SSOT v1.2.1 (Section 46.2) to govern system architecture, mechanism integrity, and compliance for `DEP-05`.

## Decision

MIT license; permissive-only dependencies

## Alternatives considered

Evaluated against alternative architectural and mechanism options during SSOT v1.0, v1.1, v1.2, and v1.2.1 audits (see Appendices E and F).

## Consequences (positive, negative, follow-ups)

- **Key reason / positive impact**: Hackathon open-source rule; license compatibility
- **Traceability**: Enforced via `DEP-05` and verified at release gates (Section 27).
